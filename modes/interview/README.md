# 面试工作流

一组可复用的端到端面试准备工作流。

## 工作流

| 工作流 | 文件 | 适用场景 |
|---|---|---|
| 备战计划 | `plan.md` | 根据 JD 和面试日期，生成结构化的分时段准备计划 |
| 模拟面试 | `practice.md` | 进行模拟面试问答并获得结构化反馈 |
| 面试复盘 | `debrief.md` | 真实面试结束后补齐能力缺口并更新题库 |

## 相关工作流（位于上级 `modes/` 目录）

| 工作流 | 文件 | 适用场景 |
|---|---|---|
| 公司研究 | `../interview-prep.md` | 面试前研究具体公司和岗位 |

## 文件约定

这些工作流默认使用下列 career-one 文件：

| 文件 | 用途 |
|---|---|
| `cv.md` | 候选人简历，是经历和成果证明的事实来源 |
| `article-digest.md` | 从作品集中提炼的精简成果证明（可选） |
| `config/profile.yml` | 候选人画像，包括目标岗位、薪酬和职业叙事 |
| `modes/_profile.md` | 候选人的职业原型、叙事和求职红线 |
| `interview-prep/story-bank.md` | 持续积累的 STAR+R 故事库 |
| `interview-prep/question-bank.md` | 带缺口跟踪的题库，首次使用时创建 |
| `interview-prep/interview-prep-guide.md` | 通用面试原则（可选） |
| `interview-prep/{company}-{role}.md` | 针对具体岗位的面试准备文件 |
| `interview-prep/retracted-claims.md` | 候选人已明确拒绝、无法自证的表述；模拟面试和复盘必须将其作为硬性门禁。格式：`**"[表述]"**（[上下文]）。原因：[一行原因，以及适用时的正确表述]。` |
